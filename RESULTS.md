# GreenLeaf Residency Helpdesk — Test Results

## 1. Project Overview

GreenLeaf Residency Helpdesk is a Retrieval-Augmented Generation (RAG) application that answers residents' questions using GreenLeaf Residency documents.

The application retrieves relevant document sections, generates answers using an AI model, and displays supporting sources.

Key capabilities:
- PDF, DOCX, Markdown, and TXT document ingestion
- Text cleaning and sensitive-data masking
- Semantic search using Qdrant
- Answer generation using Groq
- Source attribution
- Effective-date-based policy conflict handling
- Document update indexing
- Streamlit user interface
- Automated tests

## 7. Known Limitations and Improvement Areas

1. Some retrieved sources are not directly relevant to the question.
2. Source section metadata is generic for some PDF pages.
3. One generated answer contained a minor formatting typo.
4. Privacy protection should be validated with broader adversarial testing.
5. Document preprocessing should be checked to ensure cleaned pages and chunks are persisted as required by the assignment.
6. The maintenance update was verified in the current index; the before-update value was recorded from an earlier test rather than a separate isolated final run.
